Koneksi API

Key disimpan di browser ini (localStorage). Jangan bagikan file ini bersama key-nya. Untuk dipublikasikan, pakai proxy backend lewat Base URL.

Tombol "Muat daftar" mengambil model yang benar-benar tersedia di akunmu dari endpoint /models.

Grup & Skenario

Dibaca semua karakter di setiap balasan.

Aturan untuk Semua Karakter

Dibaca semua karakter di setiap balasan. Aturan khusus satu karakter diatur di panel karakter itu. Isi juga "Namamu di grup" di atas agar sapaan memakai namamu.

Parameter Percakapan

Model bernalar (reasoning) memakai token juga untuk berpikir. Jika balasan kosong atau terpotong, naikkan Maks token.

Google Drive

Karakter, pengaturan, dan riwayat chat disimpan ke file wa-roleplay-data.json di Google Drive-mu, otomatis beberapa detik setelah ada perubahan. API Key dan Base URL tidak ikut disimpan. Pakai Client ID yang sama di semua perangkat. Halaman harus dibuka lewat http://localhost atau alamat https, bukan file langsung.
